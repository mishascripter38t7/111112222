# SkyGraphite

Графитовый гражданский дашборд для публичных статусов воздушных тревог и истории событий.

## Важно: модель публикации

- Репозиторий можно хранить **Private**.
- Публикуемый сайт будет **Public**.
- GitHub Pages из приватного репозитория зависит от тарифа и настроек организации/аккаунта. На GitHub Free для личных аккаунтов Pages обычно требует публичный репозиторий. Если приватный репозиторий не поддерживается вашим тарифом, workflow не сможет опубликовать сайт.
- GitHub Pages — статический хостинг. Он не запускает Python/FastAPI и не хранит секреты на сервере.
- Никогда не помещайте API-токены в `assets/js/config.js`, HTML или другой публикуемый файл: посетители смогут их прочитать.

## Структура

```text
.github/workflows/pages.yml
assets/css/app.css
assets/js/app.js
assets/js/config.js
index.html
README.md
```

## Публикация

1. Создайте приватный репозиторий `SkyGraphite`.
2. Загрузите содержимое архива, сохранив структуру папок.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **GitHub Actions**.
5. Запустите workflow `Deploy SkyGraphite to GitHub Pages`.
6. После успешного запуска адрес сайта появится в **Settings → Pages**.

Если GitHub не разрешает Pages из приватного репозитория на вашем тарифе, варианты: подключить подходящий тариф или держать исходный репозиторий приватным, а публичную сборку публиковать в отдельный публичный репозиторий.

## Подключение данных

Откройте `assets/js/config.js`. В `sources` описаны места для публичных endpoint-ов. Сейчас они отключены намеренно: проект не показывает вымышленные события и не делает вид, что подключён к радару.

Перед подключением любого API:
- проверьте документацию, разрешённые сценарии и лимиты;
- не добавляйте секретный токен во frontend;
- если API требует секрет, используйте отдельный backend/proxy с переменными окружения;
- отображайте источник, время обновления и статус достоверности;
- не превращайте сообщения в выдуманные координаты или точные траектории.

## Ограничения

Этот проект не подключён к военным РЛС, не определяет местоположение БПЛА и не является официальной системой оповещения. Он предназначен для безопасного отображения публичных гражданских статусов и сводок.
